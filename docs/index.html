Agent ID Guestbook

An on-chain guestbook on BNB Smart Chain Testnet. Only wallets that hold an Agent ID (a .ai name) can write a message. Anyone can read.

Testnet deployment pending. The guestbook contract has not been deployed to BSC Testnet yet, so posting is disabled for now. Reading works once the contract is live. Check the repository for the latest status.

Write a message

Connect a wallet holding an Agent ID to post.

Posting sends an on-chain transaction from your wallet and costs testnet gas (tBNB). You always confirm the transaction yourself in your wallet — nothing is ever sent without your approval. This guestbook promises no rewards, income or returns of any kind.

How Agent ID is used here: the smart contract checks, on-chain, that the posting address holds at least one Agent ID (balanceOf on the Agent ID registry). That is the only use of Agent ID in this app — it gates who can write. The app does not look up anyone's wallet by name, does not collect seed phrases or private keys, and never moves anyone's funds.
